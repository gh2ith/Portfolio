# Ghaith's Portfolio

Welcome to my personal portfolio website!
This project showcases my background, skills, experience, projects, and qualifications as a software developer.

## 🚀 About the Project

**Ghaith's Portfolio** is a responsive personal portfolio website built to present my professional profile and development journey in a simple and modern way.

The website includes sections for:

* **About Me** – A short introduction and overview of my background.
* **Experience** – My previous work and training experiences.
* **Qualifications** – My educational and professional qualifications.
* **Skills** – My technical and soft skills.
* **Projects** – Projects I have worked on and developed.
* **References** – Professional references and supervisors.
* **Contact** – Information for getting in touch with me.

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling, layouts, animations, and responsive design
* **Bootstrap 5** – Responsive layout and reusable UI components
* **JavaScript** – Interactive functionality
* **Google Fonts** – Custom typography
* **Font Awesome** – Icons

## 📱 Responsive Design

The portfolio is designed to work across different screen sizes, including:

* 💻 Desktop
* 🖥️ Laptop
* 📱 Tablet
* 📲 Mobile

CSS media queries and Bootstrap's responsive utilities are used to adapt the layout to different devices.
