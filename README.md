## Getting Started

Clone the repo and open `index.html` in your browser — no build step required.

```bash
git clone https://github.com/gh2ith/[your-repo-name].git
cd [your-repo-name]
```

Then open `index.html` directly, or serve it locally:

```bash
# Using Python
python -m http.server 8000

# Using Node
npx serve
```
